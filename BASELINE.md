# Публичный baseline — 2026-09-04

Baseline описывает состояние самостоятельного проекта 1c-tj-toolkit, подготовленное
к публичной публикации. Точный состав определяется деревом Git; версии
компонентов сохраняются раздельно.

## Состав и версии

| Компонент | Версия / состояние |
|---|---|
| Анализатор `analyze_1c_tj.py` | 1.6.1 |
| Схема результата анализа | 1.6 |
| SQLite | Схема хранилища 1.1 |
| Нормализация SQL | 2.0 |
| Расчётчик `derive_slices.py` | 1.8.0, схема срезов 1.8 |
| Конфигурация срезов | 1.0; 6 примеров |
| Верификатор анализа | 1.2.0 |
| Независимый аудит первого этапа | 1.1.0 |
| Срезы | 26 таблиц |
| PDF-визуализатор | Контракт 1.0; 3 режима; анализ 1.6 и необязательные срезы 1.8 |
| Основная лицензия | MIT, copyright (c) 2026 Mikhail Baranov |
| Liberation Sans | SIL Open Font License 1.1; не входит в MIT |

В публичный состав входят модули Python, обе SQL-схемы, синтетические тесты,
примеры конфигураций, инструкции, лицензии и workflow CI. README явно фиксирует
ранний статус проекта, отсутствие аффилированности с фирмой «1С» и запрет на
публикацию реальных журналов и результатов анализа в публичных обсуждениях.

Исходные журналы, архивы, SQLite-базы, рассчитанные результаты, готовые PDF,
временные файлы, локальные настройки и исторический `TRANSFER_MANIFEST.json`
хранятся отдельно от Git. Рабочие каталоги `data/`, `output/`, `outputs/`,
`tmp/` и `work/` исключены через `.gitignore`.

## Проверка

Локально на Windows / Python 3.12.13 выполнено:

- `python -B -m unittest discover -s tools/one_c_tj_analyzer/tests -v`:
  233 теста пройдено, 1 пропущен (`OK (skipped=1)`). Проверка отказа
  чтения symlink за пределами комплекта пропущена, поскольку локальная
  среда не разрешает создание symlink (`Host does not permit symlinks`).
- `python -B -m unittest discover -s tools/one_c_tj_report/tests -v`:
  54 теста пройдено без пропусков (`OK`).
- Разбор синтаксиса всех 55 Python-файлов и чтение 13 JSON-файлов прошли без
  ошибок.
- CLI анализатора, верификаторов, расчётчика и трёх режимов PDF проверены
  отдельно от тестов содержимого.

Workflow `.github/workflows/tests.yml` сохраняет отдельный job тестов анализатора
без сторонних зависимостей и добавляет отдельный job тестов PDF с закреплёнными
ReportLab и pypdf. Оба job выполняются на Windows и Linux с Python 3.10 и 3.12.
Версии Actions закреплены SHA. Результат удалённого прогона следует смотреть
во вкладке Actions для конкретного коммита; наличие workflow само по себе
не означает успешного выполнения.

## Границы baseline

- Тесты используют синтетические журналы и сохранённые комплекты. Полный
  производственный объём, время выполнения и пик памяти здесь не измерялись.
- PDF-визуализатор принимает только анализ 1.6 / анализатор 1.6.1 и
  необязательные срезы 1.8 / расчётчик 1.8.0. Три режима используют общий
  загрузчик и искусственные конфигурации представления. Автоматические тесты
  структуры и текста PDF не заменяют ручную визуальную проверку и проверку на
  реальном полном объёме.
- Подтверждение целостности комплекта не доказывает полноту исходного ТЖ
  или причину изменения быстродействия. Границы интерпретации описаны
  в контрактах и runbook-файлах.
- Проект готовится к публичной публикации, но этот baseline сам по себе не
  подтверждает, что видимость репозитория уже изменена или что удалённый CI
  успешно выполнен. Основной код распространяется по MIT, а Liberation Sans —
  отдельно по SIL OFL 1.1.
